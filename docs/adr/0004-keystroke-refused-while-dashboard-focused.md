# A Keystroke is refused while the Dashboard is focused on that session

A Keystroke is one named key delivered to the program inside a session. Paste remains a separate operation. The Dashboard already writes keys into the session it is focused on, and a second writer would interleave with the person typing. A Keystroke is therefore refused while the Dashboard is focused on that session, and allowed when no Dashboard is attached or when the Dashboard is showing a different session. Sharing the keyboard was rejected because the two streams would mix with no owner.
