OVRCR sidebar — readability mockups

All seven windows render the same fixture at the sidebar's real width (40 cells, JetBrains Mono, Catppuccin Mocha). Every row is built as exactly 40 monospace cells, so anything shown here is drawable by the ratatui sidebar without layout tricks. Windows are live: click rows to select, chevrons and headers to fold, and type in 05's filter.

What makes the current sidebar hard to read

  • Status is invisible. The slot before each name shows - until a hook reports, and - reads as a bullet, not a state. Nothing tells you which agent is busy, waiting, or broken without attaching to it.
  • Half the rows are metadata. The provider/model line doubles the row count, and its bright orange outweighs the session names it describes. The └ under it suggests a child node when it is an attribute.
  • local / terminal repeats in every workspace. Eight of twenty-six rows in this fixture say the same thing.
  • Levels are hard to tell apart. Workspace and session names share the same white bold. Indent steps are 0, 2, 2, 5 cells, so the tree shape does not match the data shape.
  • Mauve means two things. The header band and the selected row use the same fill, so the eye lands on the header first.
  • Folded groups go dark. Collapse a workspace and any waiting or errored agent inside it vanishes.

The mockups

00 · Current open ↗

Baseline: the in-progress branch's grammar with the same fixture, for side-by-side comparison.

01 · Inline metadata open ↗

Smallest change. One row per session, model right-aligned in the provider colour, quiet header, roll-ups on folded rows.

02 · Status-led open ↗

Status column + two-letter provider tag + elapsed time. Model leaves the sidebar; the dashboard status line already shows it.

03 · Sections open ↗

No chevrons. Upper-case project headers with rules, branch glyph on workspaces, soft selection that keeps colours.

04 · Box tree open ↗

Proper ├─ │ └─ connectors at every level so structure reads as structure.

05 · Focus open ↗

Accordion: only the selected workspace is open. Filter row on top, key hints on the bottom. Scales to fifty sessions.

06 · Attention open ↗

Waiting/error sessions lifted to a NEEDS ATTENTION block. Local shells become a $ cell on the workspace row.

07 · Detail strip open ↗

Tree shows status + name only, never truncated. All metadata for the selection lives in a pinned three-line strip.
