▣ OVRCR GUI

05 · Accordion with a filter. Only the workspace holding the selection is open; the others collapse to one line with a session count and roll-up. With fifty sessions this is the difference between a list you scroll and a list you read. A filter row at the top (type in it) narrows by name and opens every workspace with a hit. Sessions show status and name only. A key hint footer replaces the need to remember the bindings. Click a folded workspace to open it and select its first session.
