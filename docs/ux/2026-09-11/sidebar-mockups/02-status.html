02 · Status first, model last. The question an agent runtime sidebar answers is "who needs me?", so the status glyph gets a fixed column and colour, followed by a two-letter provider tag (cl cx gk pi). The model name leaves the sidebar entirely: the dashboard's status line already shows it for the selected session. Elapsed time sits at the right edge so stale sessions are visible. Every workspace row carries a live roll-up, even when expanded, so you can scan a column of counts.
