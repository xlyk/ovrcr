# Superset session restoration: installed 1.28.0

Reviewed 2026-09-15. **Superset automatically executes native resume commands for eligible interrupted agent sessions. It types the command into a shell PTY and sends Enter.** Normal restoration supplies an empty prompt: it opens the conversation without submitting a new user task.

## Full resume execution path

1. `TerminalPane` mounts `TerminalAgentAutoResume`. The component rechecks candidates on transport transitions and automatically calls `terminalAgents.resume` for a supported candidate. It attempts once per candidate locally; failed attempts expose Retry. [Pane integration](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/apps/desktop/src/renderer/routes/_authenticated/_dashboard/v2-workspace/$workspaceId/hooks/usePaneRegistry/components/TerminalPane/TerminalPane.tsx#L624-L635); [Recheck](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/apps/desktop/src/renderer/routes/_authenticated/_dashboard/v2-workspace/$workspaceId/hooks/usePaneRegistry/components/TerminalPane/components/TerminalAgentAutoResume/TerminalAgentAutoResume.tsx#L70-L78); [Automatic effect and Retry](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/apps/desktop/src/renderer/routes/_authenticated/_dashboard/v2-workspace/$workspaceId/hooks/usePaneRegistry/components/TerminalPane/components/TerminalAgentAutoResume/TerminalAgentAutoResume.tsx#L125-L207).

2. The host mutation delegates to `resumeTerminalAgentSession`, wiring `runAgentInWorkspace` as launcher. It atomically claims the persisted binding, coalesces concurrent calls, and releases claims on unsupported configuration or thrown launch failure. [Mutation wiring](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/terminal-agents/terminal-agents.ts#L423-L440); [Claim and launch](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/terminal-agents/terminal-agents.ts#L123-L169); [Persistent atomic claim](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal-agents/persistence.ts#L229-L260).

3. The request carries saved `resumeSessionId`, selected agent, workspace and `prompt: ""`. The command builder combines configured command/base args/model args/resume args/session ID and shell-quotes the argv. Empty prompt means no new task prompt or prompt-mode arguments. [Resume input](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/terminal-agents/terminal-agents.ts#L151-L164); [Native command construction](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/agents/agents.ts#L139-L174).

4. `runTerminalAgent` creates a fresh terminal UUID and passes the resulting command as `initialCommand` to `createTerminalSessionInternal`. Terminal creation queues it. The queue waits for shell readiness, writes command text, then separately writes `\r` (Enter), normally after 500 ms. Its PTY adapter passes bytes to `daemon.input`. **The command is executed automatically, not left waiting for the user to press Enter.** [New terminal launch](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/agents/agents.ts#L563-L590); [Queue invocation](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L3167-L3173); [Ready gate](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L2291-L2312); [Command and Enter](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L2386-L2404); [500 ms delay](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L455-L465); [PTY adapter](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L106-L122).

5. The host records the successor terminal ID, disposes the old terminal and broadcasts a resumed event. Panes follow it or query the persisted successor when later mounted. [Successor and cleanup](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/terminal-agents/terminal-agents.ts#L171-L199); [Pane follows successor](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/apps/desktop/src/renderer/routes/_authenticated/_dashboard/v2-workspace/$workspaceId/hooks/usePaneRegistry/components/TerminalPane/components/TerminalAgentAutoResume/TerminalAgentAutoResume.tsx#L111-L123).


## Restart triggers

| Event | Behavior |
| --- | --- |
| UI/host-service reconnect while PTY daemon lives | Adopt the existing live PTY and replay its buffer; no agent relaunch needed. |
| PTY/daemon loss or reboot, eligible binding remains | Cold attach marks terminal-exited; a mounted pane discovers the candidate and automatically runs native resume in a new terminal. |
| Pane not mounted during loss | It checks on mount. This renderer path is not evidence of eager host-wide resume at startup. |
| Explicit account-switch restart | A separate host loop resumes eligible Claude/Codex sessions without waiting for panes. |

[Adopt versus cold respawn](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L3407-L3444); [Renderer mount semantics](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/apps/desktop/src/renderer/routes/_authenticated/_dashboard/v2-workspace/$workspaceId/hooks/usePaneRegistry/components/TerminalPane/components/TerminalAgentAutoResume/TerminalAgentAutoResume.tsx#L28-L40); [Host account-switch loop](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/terminal-agents/terminal-agents.ts#L240-L280). Temporarily unreachable daemons produce retryable errors rather than immediate replacement.


## Eligibility, IDs and provider limits

The host's SQLite `terminal_agent_bindings` table stores terminal ID, workspace ID, agent ID, provider session ID, agent definition ID, lifecycle timestamps/event, end reason and successor terminal ID. This is recovery metadata; the provider's native resume command supplies conversation restoration. [SQLite binding schema](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/db/schema.ts#L46-L73). The same schema was inspected in the installed bundle source map.

A candidate must match workspace/terminal, have ended with `terminal-exited`, and retain a provider session ID. Clean agent detach is excluded. A detach within 30 seconds of PTY death can be upgraded to terminal-exited; explicit disposal can override a resumable exit. [Predicate](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal-agents/persistence.ts#L137-L165); [Death/disposal classification](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal-agents/persistence.ts#L55-L118).


Agent events update persisted bindings and bindings reload on host construction. Resumed launches immediately bind the known native session ID, without waiting for hooks; the source specifically addresses Codex not emitting a hook until the next turn. This prevents an idle resumed session from losing its resume mapping if it dies again. [Binding load and updates](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal-agents/store.ts#L128-L230); [Immediate resume binding](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/agents/agents.ts#L534-L560).


Resume support is per configuration: nonempty `resumeArgs`. Built-in definitions include Claude `--resume`, Codex `resume`, Pi `--session`, Grok `--resume`, Hermes `-r`, and others. **Oh My Pi is launchable but has no built-in resume command in this release.** This is Superset configuration evidence, not independent validation of every installed provider. [Capability query](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/terminal-agents/terminal-agents.ts#L390-L413); [Claude/Codex](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/shared/src/builtin-terminal-agents.ts#L60-L96); [OMP/Pi](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/shared/src/builtin-terminal-agents.ts#L131-L147); [Grok](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/shared/src/builtin-terminal-agents.ts#L181-L189); [Hermes](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/shared/src/builtin-terminal-agents.ts#L250-L259).


**Fresh fallback exists:** only for a last event of Attached, if the provider-store probe definitely finds no persisted conversation, the helper omits `resumeSessionId` and starts fresh. Unknown/unreadable stores still attempt resume. A successful restoration result therefore does not universally mean previous conversation history was recovered. [Conditional fresh start](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/terminal-agents/terminal-agents.ts#L114-L164).


## Safeguards and limits

Shell startup handling includes readiness markers, disposal checks, output-quiescence/echo checks for unsupported or missing markers, bounded retyping and eventual fallback. Long commands can be staged in a temporary script. These address startup readers and line editors swallowing command bytes; the fallback does not prove the provider loaded its conversation. [Ready gate and staging](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L2291-L2385); [Echo/quiescence and fallback](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L2136-L2237).


`runTerminalAgent` returns after terminal creation/binding while actual command typing is deferred through a promise. `{resumed: true}` does not wait for a provider acknowledgment that history loaded. [Launch return](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/trpc/router/agents/agents.ts#L563-L590); [Deferred typing](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L2291-L2312).


Superset retains terminal presentation independently of provider history: its separate daemon keeps a bounded 512 KiB replay buffer, and cold respawn preserves the renderer's already-painted scrollback. This does not prove full disk transcript recovery across reboot. [Daemon replay](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/daemon/DaemonSupervisor.ts#L1-L42); [Cold respawn scrollback](https://github.com/superset-sh/superset/blob/a415227dc25f806dd3ef6bf05b464adba5ac08fb/packages/host-service/src/terminal/terminal.ts#L3422-L3427).


## Implication for OVRCR

**Recommendation:** reuse native provider resume and provider-owned conversation history. OVRCR still needs durable workspace/session identity, provider configuration and native conversation mapping, and a visible failed/unavailable resume state. Whether to automatically launch on restoration, as Superset does for eligible mounted panes, remains a product decision; the earlier explicit-reopen-only direction is provisional. Do not copy Superset's fresh-start fallback unless explicitly desired. This evidence explains Superset's execution mechanism; it does not require OVRCR to adopt its separate PTY daemon, terminal-output retention, launch permission flags or exact shell typing implementation.
